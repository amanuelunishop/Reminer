Telegram reminders

A page can't ping you while it's closed — nothing can, without a server. So set the pings up once with a free scheduler (cron-job.org) that messages your bot directly at each block's start time. Takes about five minutes, and it runs whether or not this site is open.

  1. Message @BotFather on Telegram → /newbot → copy the token it gives you.
  2. Message @userinfobot to get your numeric chat ID.
  3. Paste both above and hit Save, then Send test message to confirm it works.
  4. Create a free account at cron-job.org. For each row below, make a new cron job: paste the URL, set it to run daily at that exact time.
